# JNV Wargal Alumni: Android app

## [📱 Download the app (version 2, 4.0 MB)](https://github.com/jayarajuchintala/JNV-Alumni-App-Releases/raw/main/JNV-Wargal-Alumni.apk)

Updates itself: the app refreshes after site updates and can download its own new versions.

**Install:** open the link on your Android phone in Chrome, tap **Download**, then open the file and tap **Install**.
If Android asks, allow **Install unknown apps** for Chrome. Already have the app? Installing the new version keeps
your login.

The app opens the JNV Wargal Alumni network at https://alumni.jaycloudhub.com.
